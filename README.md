# aa-tushino.ru

Сайт группы Анонимных Алкоголиков «Тушино» (Москва): расписание собраний, Ежедневник АА на каждый день, контакты и карта.

Статика без сборки (HTML/CSS/vanilla JS) + один PHP-скрипт для хранения текстов Ежедневника. Хостинг — Beget (бесплатный тариф), деплой — GitHub Actions по FTPS.

## Структура

```
index.html               главная страница
admin.html               /admin — добавление текстов Ежедневника
app.js                   рендер расписания, «ближайшего собрания», Ежедневника, карты
styles.css               стили (светлая/тёмная тема)
data/
  schedule.js            расписание, темы, адрес, координаты, ссылки на чаты
  daily.js               тексты Ежедневника, вшитые в репозиторий (ключ "ММ-ДД")
api/
  daily.php              REST-хранилище текстов из /admin
  storage/               daily.json на сервере (не в git, деплой не трогает)
assets/                  шрифты (Lora, Golos Text) и Leaflet — без внешних CDN
.htaccess                rewrite /admin, заголовки, закрытие служебных файлов
.github/workflows/       тесты PHP + деплой на Beget
tools/import_daily.py    импорт Ежедневника из .txt в data/daily.js
tools/render_static.py   статичная копия расписания в index.html (для поисковиков), вызывается при деплое
docs/                    шаблон согласия на публикацию телефона (не деплоится)
```

## Локальный запуск

Без API достаточно любого статического сервера:

```bash
python -m http.server 8000
```

С API нужен PHP (подойдёт 5.6+):

```bash
php -r 'file_put_contents("api/config.php", "<?php return [\"password_hash\" => " . var_export(password_hash("dev", PASSWORD_DEFAULT), true) . "];\n");'
php -S localhost:8000
```

`api/config.php` в `.gitignore`. На `localhost` админка показывает предупреждение, но работает.

## Данные

**Расписание и контакты** — `data/schedule.js`. Каждое собрание: `day` (0 = вс … 6 = сб), `time`, `duration` (мин), `topic`, необязательные `note` и `special: { first, last }` — тема для первого/последнего такого дня недели в месяце. Пустые `phone`, `telegram`, `max` скрывают соответствующие блоки.

Время везде считается по `Europe/Moscow`, независимо от часового пояса посетителя.

**Ежедневник** собирается из двух источников, второй перекрывает первый:

1. `data/daily.js` — `window.AA_DAILY = { "10-19": { title, quote, source, text } }`;
2. `GET /api/daily.php` — то, что сохранено через `/admin`.

Абзацы в `text` разделяются пустой строкой, строки `source` — `\n`. Ключ без года, поэтому тексты повторяются ежегодно. Если на дату текста нет, показывается только ссылка на этот день на aa-online.ru.

Импорт из файла (формат — в `tools/daily-example.txt`). Скрипт **перезаписывает** `data/daily.js` целиком:

```bash
python tools/import_daily.py daily.txt
```

## API

`api/daily.php`, ответы в JSON.

| Метод | Описание |
|---|---|
| `GET` | все сохранённые дни |
| `POST` `{key, title, quote?, source?, text}` | сохранить день |
| `POST` `{check: true}` | проверить пароль |
| `DELETE ?key=MM-DD` | удалить день |

Пароль — заголовок `X-Admin-Password` или поле `password` в JSON-теле. В конфиге хранится только bcrypt-хэш. При отказе возвращается `401` и `reason`: `no_config`, `no_password` или `mismatch`.

Запись в `daily.json` идёт под `flock`. Код совместим с PHP 5.6 — это версия по умолчанию на бесплатном тарифе Beget.

## Деплой

Любой пуш в `main` запускает `.github/workflows/deploy.yml`:

1. тесты `api/daily.php` на PHP 5.6 и 8.3 (docker, curl);
2. генерация `api/config.php` из секрета `ADMIN_PASSWORD`;
3. статичное расписание в `index.html` из `data/schedule.js` и версия коммита в `?v=` у всех CSS/JS;
4. загрузка по FTPS (`SamKirkland/FTP-Deploy-Action`) — только изменённые файлы.

Секреты репозитория: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `ADMIN_PASSWORD`. Необязательная переменная `FTP_DIR` (по умолчанию `./` — FTP-аккаунт смотрит прямо в `public_html`). Без секретов выполняются только тесты.

Смена пароля админки: обновить секрет `ADMIN_PASSWORD` и перезапустить workflow.

## Известные ограничения

- **Нет HTTPS.** На бесплатном тарифе Beget нет выпуска SSL. После появления сертификата нужно добавить редирект на https в `.htaccess` (там оставлено место).
- Подпись © OpenStreetMap на карте обязательна по лицензии ODbL — не убирать.
- Телефон группы скрыт, пока нет письменного согласия владельца номера на распространение (152-ФЗ, ст. 10.1). Шаблон — `docs/`.
- Текст Ежедневника АА — литература АА, защищённая авторским правом. На сайт попадают только тексты, которые добавляет группа.

# Сайт группы АА «Тушино»

Статический сайт без сборки: обычные HTML, CSS и JS. Живой адрес: https://tushinoaa.netlify.app/

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы: блоки «Что такое АА», ссылки, подвал |
| `styles.css` | Оформление (светлая и тёмная тема, мобильная версия) |
| `app.js` | Логика: бар недели, «ближайшее собрание», размышление дня |
| `data/schedule.js` | **Расписание, темы собраний, адрес, телефон, координаты для карты** |
| `data/daily.js` | **Ежедневник АА — тексты на каждый день года** (создаётся скриптом) |
| `tools/import_daily.py` | Скрипт: переводит текст ежедневника из .txt в `data/daily.js` |
| `admin.html` | **Страница /admin: добавление дней Ежедневника через браузер** |
| `api/daily.php` | Серверная часть для Beget: хранит дни из /admin в `api/storage/daily.json` |
| `.htaccess` | Настройки веб-сервера Beget (адрес /admin, защита служебных файлов) |
| `.github/workflows/deploy.yml` | Проверка и автоматическая публикация на Beget по FTP |
| `assets/` | Шрифты и библиотека карты — лежат на сайте, без внешних CDN |
| `netlify/functions/daily.mjs`, `netlify.toml` | Старый вариант для Netlify (в России работает плохо) |

Чаще всего нужно править только два файла в `data/`.

## Как добавлять дни Ежедневника (страница /admin)

1. Откройте https://tushinoaa.netlify.app/admin и введите пароль.
2. Выберите дату → «Открыть этот день на aa-online.ru» → скопируйте текст дня.
3. Вставьте его в большое поле — он сам разложится на заголовок, цитату, источник и текст.
4. Проверьте предпросмотр и нажмите «Сохранить».

Дни хранятся без года (ключ «ММ-ДД»), поэтому на следующий год всё показывается само.
Внизу страницы — календарь: видно, какие дни уже заполнены.

**Пароль** задаётся в GitHub: Settings → Secrets and variables → Actions → секрет
`ADMIN_PASSWORD`. Чтобы сменить пароль, измените секрет и перезапустите публикацию
(вкладка Actions → «Проверка и публикация» → Run workflow).

## Публикация на Beget (основной хостинг)

Каждое изменение в ветке `main` на GitHub автоматически проверяется и выкладывается на Beget.
Один раз нужно задать в GitHub (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `FTP_SERVER` | адрес FTP-сервера из панели Beget (раздел FTP) |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `ADMIN_PASSWORD` | пароль для страницы /admin |

FTP-аккаунт в Beget создаётся с папкой `/<сайт>/public_html` — тогда больше ничего указывать не нужно.
Если FTP-аккаунт смотрит в другую папку, добавьте переменную `FTP_DIR` (вкладка Variables).

Тексты, сохранённые через /admin, лежат на хостинге в `api/storage/daily.json`;
публикация этот файл не трогает.

## Как загрузить Ежедневник АА файлом

1. Сохраните тексты в обычный файл `.txt` (кодировка UTF-8), каждый день начинается
   со строки `# 1 января`. Образец: `tools/daily-example.txt`.
2. В папке проекта выполните:
   ```bash
   python tools/import_daily.py путь/к/ежедневник.txt
   ```
3. Скрипт перезапишет `data/daily.js` и скажет, сколько дней загружено.
   Сайт сам показывает текст на сегодняшнюю дату (по московскому времени).
   На дни без текста показывается только кнопка на aa-online.ru.

## Как посмотреть локально

Откройте `index.html` двойным щелчком, сайт откроется в браузере.

## Старый вариант: Netlify

### Вариант 1. Перетащить папку (проще всего, но без /admin)
1. Откройте https://app.netlify.com/projects/tushinoaa/deploys
2. Внизу страницы есть область *«Drag and drop your project folder here»*.
3. Перетащите туда **всю папку** `tushinoaa` (в которой лежит `index.html`).
4. Через несколько секунд обновится https://tushinoaa.netlify.app/

После каждой правки повторяйте шаг 3.

### Вариант 2. Через GitHub (рекомендуется: работает /admin, обновление автоматически)
1. Создайте репозиторий на GitHub и загрузите туда эту папку (`git push`).
2. В Netlify: *Project configuration → Build & deploy → Link repository*, выберите репозиторий.
3. Build command оставьте пустым, Publish directory: `.`
4. Теперь каждый `git push` сам обновляет сайт. Править файлы можно прямо на сайте GitHub.

### Вариант 3. Из командной строки
```bash
npm install -g netlify-cli
netlify login
netlify link        # выбрать проект tushinoaa
netlify deploy --prod --dir .
```
